Maintenance decisions under limited budgets

Prioritize Pennsylvania's bridges.

Ben² Bridges is a decision-support tool designed to help governments identify which Pennsylvania highway bridges should receive maintenance when funding is limited.

Project purpose

Move beyond age and current condition alone.

The project aims to combine predicted deterioration with current condition, traffic volume, detour impact, and estimated maintenance cost, then recommend a set of bridges that fits a selected maintenance budget.

01

Anticipate deterioration

Use historical National Bridge Inventory inspection records to estimate which bridges are most likely to decline.

02

Prioritize within a budget

Balance risk, consequences, and estimated maintenance cost to identify a practical set of bridges for intervention.

03

Compare strategies

Compare predictive prioritization with simpler policies based on age, traffic, and present bridge condition.

Technical approach

From historical inspections to maintenance priorities.

This section records the planned approach from the proposal. Final model choices, features, evaluation results, and scoring formulas can be added here once that work is complete.

1. Prepare historical data

Clean Pennsylvania National Bridge Inventory records, identify important fields, and match bridges across years using consistent identifiers.

2. Model deterioration

Create a deterioration target, engineer features, and compare logistic regression with tree-based models using a time-based split.

3. Allocate the budget

Combine predicted deterioration, current condition, traffic, detour impact, and estimated cost into a priority score and budget-constrained selection.
